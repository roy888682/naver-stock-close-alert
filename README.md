# 네이버증권 종가 알림

한국·미국 주식의 **확정된 정규장 종가**가 직접 정한 목표가 범위에 들어오면 이메일을 보내는 개인용 프로그램입니다. 브라우저 화면에서 종목과 알림 조건을 관리하며, 기본 수신 주소는 `ykhan@dacpole.com`, 기본 발신 주소는 `royhan88888@gmail.com`입니다.

## 할 수 있는 일

- 한국 종목코드와 미국 티커를 입력하고, 목표가·상단 `+%`·하단 `-%`를 각각 설정합니다.
- 종목을 여러 개 등록하고 수정·일시정지·삭제합니다.
- 종가 조회만 하거나, 조건을 확인하고 이메일을 발송합니다.
- `진입 시` 또는 `거래일마다` 알림을 선택하고, 발송 기록을 확인합니다.
- 이메일 설정과 앱 비밀번호를 화면에서 저장합니다. 종목과 알림 기록도 다음 실행 때 유지됩니다.

예를 들어 목표가가 **100,000원**, 상단이 **+5%**, 하단이 **-5%**이면 **95,000원 이상 105,000원 이하**일 때 조건을 만족합니다. 미국 주식의 목표가는 **미국 달러(USD)**로 입력합니다. 환율을 적용한 원화 가격이 아닙니다.

## Windows에서 시작하기

1. [Python 3.11 이상](https://www.python.org/downloads/windows/)을 설치합니다. 설치할 때 `Add python.exe to PATH`를 선택합니다.
2. 이 저장소를 다운로드하거나 복제하고 압축을 풉니다.
3. `run.bat`를 실행합니다. 처음 실행할 때 가상환경과 시간대 데이터가 설치됩니다.
4. 브라우저에서 [http://127.0.0.1:8765](http://127.0.0.1:8765)를 엽니다. 자동으로 열리지 않아도 이 주소로 접속할 수 있습니다.
5. **이메일 설정**에서 발신 Gmail 계정의 **앱 비밀번호**를 입력하고 **저장**합니다. 기본 발신 주소와 SMTP 설정은 이미 들어 있습니다.
6. **테스트메일**을 보내 도착을 확인한 뒤 종목과 목표가를 등록합니다.

프로그램 창을 닫으면 자동 확인도 종료됩니다. **GitHub에 코드를 올리는 것만으로 자동 감시가 실행되지는 않습니다.** 계속 알림을 받으려면 PC에서 프로그램을 실행해 두거나, 켜져 있는 서버에서 Docker로 운영해야 합니다. 기본 확인 주기는 30분이며 설정에서 변경할 수 있습니다.

이미 실행 중일 때 `run.bat`를 다시 누르면 기존 웹 화면을 엽니다. 감시 프로그램을 두 개 실행하지 않습니다. 이전 버전에서 “같은 데이터 폴더를 사용하는 프로그램이 이미 실행 중”이라는 메시지가 나온 경우에도 [웹 화면](http://127.0.0.1:8765)에 접속하면 계속 사용할 수 있습니다.

### 터미널에서 실행하기

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m stock_alert
```

macOS·Linux에서는 `python3 -m venv .venv`를 사용하고, 이후 명령의 실행 파일을 `.venv/bin/python`으로 바꿉니다.

```text
python -m stock_alert                  # 웹 화면과 자동 확인 실행
python -m stock_alert --no-browser     # 브라우저 자동 열기 없이 실행
python -m stock_alert --once           # 저장된 조건으로 한 번 확인·알림 발송 후 종료
python -m stock_alert --check-only     # 종가만 확인하고 이메일 없이 종료
python -m unittest discover -s tests -v
```

단발 실행은 웹 화면에서 종목과 SMTP 설정을 먼저 저장한 뒤 사용합니다. 중복 알림 기록을 유지하려면 항상 같은 작업 폴더와 `data/alerts.db`를 사용하세요.

## 이메일 설정

SMTP 서버·포트·보안 방식·사용자명·발신 주소와 앱 비밀번호를 화면에서 설정합니다. 기본 발신 계정은 `royhan88888@gmail.com`이고 Gmail의 `smtp.gmail.com`, 포트 `465`, `SSL` 설정을 사용합니다. 해당 Gmail 계정에서 발급한 앱 비밀번호를 입력하고 저장하면 즉시 적용됩니다. 프로그램을 다시 실행할 필요가 없습니다.

비밀번호 칸을 비워 두고 저장하면 기존 비밀번호를 유지합니다. 저장된 비밀번호는 화면에 다시 표시하지 않으며 **비밀번호 삭제** 버튼으로 지울 수 있습니다. 비밀번호를 GitHub에 올리거나 채팅에 보내지 마세요.

### Gmail 예시

| 설정 | 값 |
| --- | --- |
| SMTP 서버 | `smtp.gmail.com` |
| 포트 | `465` |
| 보안 | `SSL` |
| 사용자명 | `royhan88888@gmail.com` |
| 발신 주소 | `royhan88888@gmail.com` |
| 앱 비밀번호 | Google에서 발급한 앱 비밀번호 |

Gmail 계정에 2단계 인증을 설정하고 [Google 앱 비밀번호 안내](https://support.google.com/accounts/answer/185833?hl=ko)에 따라 발급합니다. 일반 로그인 비밀번호를 쓰지 마세요. 조직 계정 정책에 따라 앱 비밀번호를 사용할 수 없을 수 있습니다. `587` 포트를 사용하는 서버라면 보안을 `STARTTLS`로 바꿉니다.

회사 메일을 사용하려면 관리자에게 SMTP 서버·포트·TLS 방식·SMTP 인증 가능 여부를 확인합니다. `ykhan@dacpole.com`은 수신 주소이므로, 발신 계정은 별도로 설정할 수 있습니다. 회사 메일의 OAuth 전용 인증이나 별도 승인 정책이 있으면 그 정책에 맞는 SMTP 릴레이가 필요합니다.

테스트메일은 화면에서 버튼을 누를 때 발송됩니다. SMTP 설정이 끝나기 전에는 실제 알림 메일을 보낼 수 없습니다. 이메일은 첨부파일 없는 일반 텍스트입니다. 발송 성공은 SMTP 서버가 메일을 접수했다는 뜻이며 수신함 도착까지 보장하지는 않습니다. 테스트메일이 도착하지 않으면 발송 기록·오류 메시지와 수신함의 스팸함을 확인하세요.

## 종목과 알림 조건

| 입력 | 설명 |
| --- | --- |
| 시장 | 한국 또는 미국 |
| 티커 | 한국은 `005930`처럼 6자리 종목코드, 미국은 `AAPL` 같은 티커 |
| 목표가 | 한국은 KRW, 미국은 USD 기준의 양수 |
| 상단 +% | 목표가보다 위쪽의 허용 비율. 기본 `5` |
| 하단 -% | 목표가보다 아래쪽의 허용 비율. 기본 `5` |
| 알림 방식 | `진입 시` 또는 `거래일마다` |

하단은 `목표가 × (1 − 하단% / 100)`, 상단은 `목표가 × (1 + 상단% / 100)`이며 양 끝값을 포함합니다. 예시 종목은 설명용입니다. 사용자가 등록하기 전에는 자동으로 감시하지 않습니다.

**진입 시 알림**은 처음 확인한 종가가 범위 안에 있거나, 이후 종가가 범위 밖에서 안으로 들어오면 한 번 보냅니다. 계속 범위 안이면 다시 보내지 않으며, 범위 밖으로 나갔다가 재진입하면 다시 보냅니다. **거래일마다 알림**은 조건을 만족하는 거래일마다 한 번 보냅니다. 같은 종목·조건·종가 날짜의 반복 확인은 중복 발송을 방지합니다.

종가는 해당 거래소의 실제 거래일을 기준으로 표시합니다. 한국은 한국 시간, 미국은 뉴욕 시간과 서머타임을 고려합니다. 당일 일별 데이터는 **한국 16:35 KST 이후**, **미국 17:00 뉴욕 시간 이후**이고 네이버가 **장 마감 상태**를 제공하는 경우에만 사용합니다. 그 전에는 이전 완료 거래일의 종가를 사용합니다. 장중 현재가·시간외 거래 가격을 당일 확정 종가로 사용하지 않습니다. 휴장일에는 최신 완료 거래일이 유지되므로 같은 종가로 알림이 반복되지 않습니다. 최신 완료 종가가 **7일보다 오래된 경우**에는 오래된 시세로 새 알림을 보내지 않고 조회 오류로 처리합니다.

네이버증권의 공개 데이터 조회 경로는 공식적으로 안정성이 보장된 개발자 API가 아닙니다. 응답 형식이나 접근 정책이 바뀌면 조회가 실패할 수 있으며 화면에 오류가 표시됩니다. 미국 종목은 네이버에서 지원하는 종목 범위에 한정됩니다.

## Docker로 계속 실행하기

Docker와 Docker Compose를 설치한 PC 또는 서버에서 다음을 실행합니다.

```text
docker compose up -d --build
docker compose logs -f
```

[http://127.0.0.1:8765](http://127.0.0.1:8765)의 이메일 설정에서 앱 비밀번호를 저장하고 테스트메일을 보냅니다. 별도 설정 파일 편집은 필요 없습니다. 종목·이메일 설정·알림 기록과 저장한 비밀번호는 `alert-data` 볼륨에 보존됩니다.

```text
docker compose down             # 중지. 데이터 볼륨은 유지
docker compose up -d            # 다시 시작
```

기본 구성은 같은 PC에서만 접속할 수 있습니다. 이 개인용 화면에는 인터넷 공개용 로그인 기능이 없으므로 포트를 외부에 개방하지 마세요. 다른 PC에서 사용해야 한다면 인증이 있는 VPN이나 접근 제어를 먼저 구성하세요.

## Windows 로그인 시 자동 실행

Windows 작업 스케줄러에서 **기본 작업 만들기 → 로그온할 때**를 선택하고 다음처럼 등록할 수 있습니다. 아래 경로는 실제 다운로드 위치로 바꿉니다.

| 항목 | 값 |
| --- | --- |
| 프로그램 | `C:\프로그램경로\naver-stock-close-alert\.venv\Scripts\python.exe` |
| 인수 | `-m stock_alert --no-browser` |
| 시작 위치 | `C:\프로그램경로\naver-stock-close-alert` |

설정의 “작업이 이미 실행 중이면 새 인스턴스를 시작하지 않음”을 선택하세요. 먼저 `run.bat`로 초기 설정을 완료합니다. PC가 절전·종료 상태이면 확인할 수 없습니다.

## 파일과 보관

- `data/alerts.db`: 종목, 비밀번호 외 SMTP 설정, 조회 상태, 발송 기록. 백업할 때 프로그램을 중지한 뒤 `data/`를 복사합니다.
- `data/smtp-credential.json`: 웹에서 저장한 앱 비밀번호입니다. Windows에서는 같은 PC의 같은 Windows 계정에서 복호화하는 DPAPI로 보호합니다. Linux·Docker에서는 소유자만 읽고 쓰는 권한(`600`)의 별도 파일로 저장합니다. Linux·Docker의 저장 파일은 암호화되지 않으므로 관리자나 루트 사용자는 읽을 수 있습니다.
- `.env`: 기존 방식과의 호환을 위한 선택 설정입니다. 사용하지 않아도 됩니다. 사용한다면 저장소와 백업 공유 대상에서 제외합니다.
- `.github/workflows/tests.yml`: GitHub에 올린 코드의 테스트 실행용입니다. 주가 감시나 이메일 발송 스케줄이 아닙니다.

`.gitignore`는 `.env`, `data/`, 가상환경을 제외합니다. GitHub에 올리기 전에도 실제 비밀번호가 소스·스크린샷·로그에 포함되지 않았는지 확인하세요.

다른 GitHub 저장소에 등록한 Secrets는 이 프로그램에 자동으로 복사되지 않습니다. 이 저장소의 테스트 워크플로에는 메일 비밀번호를 넣을 필요가 없습니다. 기존 실행 환경의 `SMTP_PASSWORD`나 `.env`를 사용하는 방식도 호환을 위해 유지합니다.

웹에서 저장한 비밀번호가 기존 환경변수 설정보다 우선합니다. 웹에서 **비밀번호 삭제**를 누르면 기존 환경변수 비밀번호도 자동으로 재사용하지 않습니다. 발신 사용자명이나 SMTP 서버를 바꾸면 이전 비밀번호는 재사용하지 않으므로 새 비밀번호를 등록하세요.

## 다른 PC에서 실행하기

다른 Windows PC에도 Python 3.11 이상을 설치하고 ZIP을 풀어 `run.bat`를 실행하면 됩니다. 각 PC의 웹 화면에서 종목·목표가와 앱 비밀번호를 따로 등록하세요. ZIP에는 개인 설정과 비밀번호가 포함되지 않습니다. 두 PC에서 같은 조건을 동시에 감시하면 각각 메일을 보낼 수 있습니다.

## 다음에 추가하면 유용한 기능

- **메일 도달 확인과 장애 알림**: SMTP 실패나 시세 조회 중단을 별도 채널로 알려주기.
- **CSV 가져오기·내보내기**: 종목이 많아질 때 목표가를 한 번에 관리하기.
- **목표가 유효기간**: 실적 발표나 투자 계획이 지난 조건을 자동으로 중지하기.
- **공식 시세 API 연결**: 장기 운영할 때 제공 조건과 지원 범위가 명확한 데이터 서비스로 교체하기.

이 프로그램은 조건에 맞는 가격 알림을 제공하며 주문 기능은 포함하지 않습니다.
