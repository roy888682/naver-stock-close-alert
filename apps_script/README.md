# Google에서 무료로 종가 알림 실행하기

이 버전은 **Google Sheets에 종목과 목표가를 입력**하면 Google이 약 30분 간격으로 확인합니다. 설치를 마치면 PC와 브라우저를 꺼도 확인할 수 있습니다. Python 설치나 Gmail 앱 비밀번호는 필요 없습니다.

**파일을 다운로드하거나 GitHub에 올리는 것만으로 자동 감시가 시작되지는 않습니다.** 아래 절차에 따라 본인 Google 계정에서 코드를 설치하고 권한을 승인해야 합니다. 실제 Google 계정에서의 설치·실행 확인을 대신하는 문서는 아닙니다.

## 1. 발신할 Google 계정으로 시트 만들기

1. Google에 **`royhan88888@gmail.com`**으로 로그인합니다. 여러 계정에 로그인되어 있다면 오른쪽 위 프로필에서 현재 계정을 확인합니다.
2. [Google Sheets](https://sheets.google.com/)에서 **빈 스프레드시트**를 만듭니다. 이름은 `주가 종가 알림` 등으로 지정합니다.
3. 시트 위쪽의 **확장 프로그램 → Apps Script**를 선택합니다.

이 프로그램은 실행 계정이 `royhan88888@gmail.com`인지 확인합니다. 다른 Google 계정으로 실행하면 설정이나 발송을 중단합니다. 메일은 트리거를 만든 계정에서 발송됩니다. [Google의 트리거 실행 계정 설명](https://developers.google.com/apps-script/guides/triggers/installable#restrictions)

시트의 **확장 프로그램**에서 시작해야 나중에 시트에 **주가 알림** 메뉴가 표시됩니다. Google 공식 문서상 사용자 메뉴는 시트에 연결된 스크립트에서 지원합니다. [사용자 메뉴 안내](https://developers.google.com/apps-script/guides/menus)

## 2. 파일 네 개 넣기

Apps Script 편집기에서 다음 파일을 준비합니다.

| 파일 | 넣는 방법 |
| --- | --- |
| `Code.gs` | 처음 보이는 파일의 내용을 지우고 이 폴더의 `Code.gs` 내용을 복사 |
| `Naver.gs` | 파일 옆 **+ → 스크립트**에서 `Naver`를 만든 뒤 내용 복사 |
| `Monitor.gs` | **+ → 스크립트**에서 `Monitor`를 만든 뒤 내용 복사 |
| `appsscript.json` | 아래 방법으로 표시한 뒤 이 폴더의 같은 파일 내용으로 교체 |

왼쪽 **프로젝트 설정(톱니바퀴)**에서 **편집기에 appsscript.json 매니페스트 파일 표시**를 선택하면 JSON 파일이 보입니다. 내용 교체 후 모든 파일을 저장합니다. [Google 매니페스트 편집 안내](https://developers.google.com/apps-script/concepts/manifests#editing_a_manifest)

별도의 웹 앱 배포나 공개 게시 작업은 필요 없습니다. 시트와 Apps Script 프로젝트를 공개하지 마세요. 종목과 목표가는 개인 시트에 저장합니다.

## 3. 처음 한 번 `setup` 실행하기

1. 편집기 위쪽 함수 선택란에서 **`setup`**을 선택하고 **실행**을 누릅니다.
2. 권한 확인 화면이 나오면 **`royhan88888@gmail.com`**을 선택합니다. 본인이 만든 프로젝트인지 확인한 뒤 시트 관리·외부 시세 조회·메일 발송·자동 실행 및 계정 확인에 필요한 권한을 승인합니다.
3. 실행이 완료되면 원래 시트로 돌아갑니다. **관심종목**, **설정**, **알림기록** 탭이 만들어집니다.
4. 시트를 새로고침하면 위쪽에 **주가 알림** 메뉴가 나타납니다.

Google은 필요한 서비스에 접근하기 전에 사용자 승인을 요구합니다. 권한을 일부 거부하거나 나중에 취소하면 해당 기능이 실행되지 않을 수 있습니다. [Google 권한 승인 안내](https://developers.google.com/apps-script/guides/services/authorization)

`setup`은 약 30분마다 실행하는 `stockCheck` 시간 트리거와 종목 편집을 처리하는 `stockEdited` 트리거를 등록합니다. 같은 프로젝트에서 `setup`을 다시 실행해도 감시용 트리거가 중복으로 늘어나지 않도록 구성되어 있습니다. 처음에는 감시할 종목이 비어 있으며 샘플 종목을 자동으로 켜지 않습니다.

## 4. 메일을 확인하고 종목 입력하기

먼저 **설정** 탭의 수신 이메일이 **`ykhan@dacpole.com`**인지 확인합니다. **주가 알림 → 테스트메일 보내기**를 실행하거나 Apps Script 편집기에서 **`sendTestEmail`**을 실행합니다. 이 작업은 실제 테스트메일 한 통을 보냅니다. 수신함과 스팸함을 확인하세요.

그다음 **관심종목** 탭의 2행부터 입력합니다. **B열 체크박스는 나머지 조건을 입력한 뒤 마지막에 켜는 편이 편리합니다.**

| 열 | 입력할 내용 |
| --- | --- |
| B: 감시 | 확인할 종목의 체크박스를 켭니다. 끄면 그 종목은 중지됩니다. |
| C: 시장 | 한국은 `KR`, 미국은 `US` |
| D: 티커 | 한국은 `005930`처럼 6자리 코드, 미국은 `AAPL` 같은 티커 |
| E: 종목명 | 조회 후 자동 표시됩니다. |
| F: 목표가 | 한국은 원(KRW), 미국은 달러(USD). 양수를 입력합니다. |
| G: +% | 위쪽 허용 비율. `5`를 넣으면 +5%입니다. |
| H: -% | 아래쪽 허용 비율. `5`를 넣으면 -5%입니다. |
| I: 알림 방식 | `entry`는 범위 진입 시, `daily`는 조건을 만족하는 거래일마다 |

숨겨진 **A열 종목 ID**는 수정하지 않습니다. **J열 종가, K열 거래일, L열 상태, M열 확인 시각, N열 오류**는 자동 표시 영역입니다. 열 순서나 제목을 바꾸지 마세요.

예를 들어 목표가가 100,000원이고 상단·하단이 각각 5%이면 **95,000원 이상 105,000원 이하**의 종가를 찾습니다. `5%` 대신 숫자 **`5`**를 입력하세요. 예시 가격은 입력 방법을 설명하기 위한 값입니다.

상단·하단은 각각 0~100 사이 숫자이며, 빈칸은 5로 처리합니다. 한 프로젝트에 등록하는 종목은 최대 100개입니다. 무료 실행 시간 한도를 고려해 처음에는 20개 이하로 시작하고 실행 시간을 확인하세요. 많은 행을 한 번에 붙여 넣으면 이름 조회는 처음 20행까지 즉시 처리하며, 나머지 감시 종목은 자동 확인할 때 이름이 갱신됩니다.

`entry`는 처음 확인한 종가가 범위 안이거나 범위 밖에서 안으로 들어왔을 때 알립니다. 계속 범위 안이면 반복하지 않고, 밖으로 나갔다가 재진입하면 다시 알립니다. `daily`는 조건을 만족하는 거래일마다 한 번 알립니다. 같은 거래일을 반복 확인해도 중복 발송을 막습니다.

현재 PC용 프로그램에 입력한 조건은 이 시트로 자동으로 옮겨지지 않습니다. 클라우드에서 사용할 종목과 조건을 시트에 입력하세요.

메일 요청 전 발송 예정 상태를 저장해 실행 중단 뒤 중복 발송을 막습니다. 메일 접수 여부를 알 수 없는 오류가 나면 해당 종목의 자동 재발송을 멈춥니다. 수신함·스팸함과 알림기록을 확인한 뒤 조치하세요. 목표가·비율·티커·알림 방식·수신 주소를 변경하면 새 조건으로 처리하므로 이전 조건과 별개로 알림이 다시 발생할 수 있습니다. 단순히 체크를 껐다 켜거나 표시 이름을 바꾸는 것은 발송 상태를 초기화하지 않습니다.

## 5. 확인·일시정지·다시 시작

시트의 **주가 알림** 메뉴를 사용하거나 Apps Script 편집기에서 아래 함수를 선택해 실행합니다.

| 함수 | 하는 일 |
| --- | --- |
| `stockCheckOnly` | 종가와 조건만 확인. 이메일을 보내지 않음 |
| `stockCheck` | 지금 확인하고 새 알림 조건에 해당하면 이메일 발송 |
| `sendTestEmail` | 테스트메일 한 통 발송 |
| `stopMonitoring` | 이 프로젝트의 자동 감시 중지 |
| `setup` | 자동 감시 다시 설정 |

설치 후에는 **Apps Script 왼쪽 트리거(시계 모양)**에서 `stockCheck`와 `stockEdited`가 등록되었는지 확인합니다. **실행** 화면에서 최근 실행의 성공·실패를 확인하고, 시트의 오류 열과 **알림기록**도 살펴보세요. 메뉴가 안 보이면 시트를 다시 열거나 편집기에서 함수를 실행할 수 있습니다.

## 무료 한도와 확인 시각

일반 Gmail 계정 기준으로 이메일 **하루 수신자 100명**, 외부 URL 조회 **하루 20,000회**, 시간 트리거 실행 **하루 총 90분**, 실행 한 번당 **6분** 제한이 있습니다. 한 명에게 여러 번 보낸 메일도 발송 횟수만큼 수신자 할당량을 사용합니다. 한도를 넘으면 실행이 중단될 수 있으며 Google의 한도는 변경될 수 있습니다. [Google Apps Script 할당량](https://developers.google.com/apps-script/guides/services/quotas)

시간 트리거는 정확히 매시 00분·30분에 실행된다는 보장이 없습니다. 종가 알림은 거래일마다 한 번 바뀌는 가격을 확인하므로 약 30분 주기로 운영합니다. [시간 트리거 안내](https://developers.google.com/apps-script/guides/triggers/installable#time-driven_triggers)

장중 현재가나 시간외 가격을 당일 확정 종가로 사용하지 않습니다. 당일 종가는 한국 **16:35 KST 이후**, 미국 **17:00 뉴욕 시간 이후**이고 네이버의 마감 상태도 확인된 경우에 사용합니다. 이전 완료 거래일이나 휴장일의 날짜가 표시될 수 있습니다. 오래된 시세와 네이버 조회 오류는 오류 열에서 확인하세요.

## 메뉴 없는 독립 프로젝트로 설치했다면

[Apps Script](https://script.google.com/)에서 직접 새 프로젝트를 만들고 파일 네 개를 넣은 뒤 `setup`을 실행하는 방법도 지원합니다. 이 경우 새 스프레드시트를 만들지만 시트에 사용자 메뉴가 자동으로 표시되는 방식은 아닙니다. 설정 결과에서 생성된 시트 주소를 확인하고, 실행은 편집기의 함수 선택란을 사용합니다. 처음 사용하는 경우에는 위의 **빈 시트 → 확장 프로그램 → Apps Script** 방법을 권합니다.
